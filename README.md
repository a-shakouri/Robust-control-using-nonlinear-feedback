# Robust control using nonlinear dynamic state-feedback

MATLAB code for the example in Ref.[^1]. 

## File(s)

This repository includes the following MATLAB files: 

1- Example of a two-wheeled inverted pendulum mobile platform: Example.m.

2,3,4- Construction of the nonlinear dynamic feedback law: f_fun.m, g_fun.m, & phi_fun.m.

5- Finding the vertices of a polytopic set of matrices: vertices.m

6- Choosing an element within a polytopic set: sys_eval_box.m.

7- Finding the vertices of a polytopic set of matrices: qs_vertices.m.

8- Covering a polytopic set of systems with a finite number of quadratically stabilizable subsets: setcover.m.
